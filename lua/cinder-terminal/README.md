# cinder-terminal.nvim

A persistent floating terminal workspace for Neovim. It uses
[snacks.nvim](https://github.com/folke/snacks.nvim) for the floating layout and
keeps terminal sessions alive when the workspace is hidden.

The plugin is managed as a local LazyVim plugin from
`lua/plugins/cinder-terminal.lua`.

See `doc/cinder_terminal.txt` for the complete API and configuration reference.
