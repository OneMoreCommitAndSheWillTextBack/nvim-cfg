==============================================================================
PLUGIN-MANAGED MAPPINGS
------------------------------------------------------------------------------
Some plugins handle mappings inside their own keymap engine, so they do not
appear in :verbose {mode}map output:
  <leader>as (Normal, Insert)  Toggle Minuet automatic completion and notify
                               the current state
                               lua/plugins/minuet.lua:159-164,176-182
  <leader>ad (Normal, Insert)  Toggle between the active provider and its
                               `-duet` profile
                               lua/plugins/minuet.lua:133-135,183-188
  <leader>ap (Normal)           Select a generated Minuet provider profile
                               lua/plugins/minuet.lua:138-157,189-194
The `<leader>as` mapping is a normal/insert mode Vim mapping and toggles Minuet
Blink auto-completion. Its default state is disabled.
